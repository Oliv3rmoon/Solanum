Solanum 0.2.0: a catalog of 56 open-source apps, every release pinned by its SHA-256, and everything a store should
do with what it installs: uninstall, roll back, older versions, holds, any drive, custom catalogs and ten languages.

**Install:** unzip `PPSA76526.zip` and copy its `PPSA76526` folder to `/data/homebrew/` with permissions `777`, over
0.1.0 or new. It needs the HEN's payload loader (port 9021) for its install helper and launch payload. 0.1.0 updates
itself to it.

- **56 apps**, up from 6: media players and clients for your own servers, emulators, engine ports that need your own
  game files, games and tools, each open source with no game files. Search them by tag (`#emulator`, `#ps1`).
- **Every release is pinned:** the catalog's workflow downloads each app's newest release, checks it and records
  its SHA-256; Solanum checks every download against it before anything is unpacked. Releases without a checksum
  file install too, and showing the whole catalog costs GitHub's hourly limit nothing.
- **Uninstall** (the app's folder and home-screen entry, its data if you tick it), **Roll back** in one press from
  the copy Solanum kept, **Versions** to install any release, **Skip** or **Hold** updates, **Update all**, and
  automatic updates if you switch them on.
- **Install on** internal storage, an extended drive or a USB drive, with a free-space check.
- **Custom catalogs** (Settings > Catalogs): a GitHub repository or an HTTPS catalog.json, always third-party.
- **Ten languages**, a **Downloads** queue that runs a few at once, a **USB keyboard**, each app's stars, and a QR
  code to its source.
- Apps you installed by hand are found on any drive ShadowMountPlus scans, and looked after from then on.

Check the download with `gh attestation verify PPSA76526.zip -R Oliv3rmoon/Solanum`, or against `SHA256SUMS`.
