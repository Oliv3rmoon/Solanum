The first Solanum, a Nightshade app: a store for open-source PS5 homebrew. It installs and updates the apps of the
open [Solanum catalog](https://github.com/Oliv3rmoon/Solanum-Catalog) from their own GitHub releases, each checked
against its checksums before anything is unpacked, in Nightshade's black and red.

**Install:** unzip `PPSA76526.zip` and copy its `PPSA76526` folder to `/data/homebrew/` with permissions `777`.
It needs the HEN's payload loader (port 9021) for its install helper and launch payload.

- Browse the catalog by category (the Nightshade family first) or search it; each app has a page with its license,
  an attested badge, its newest version, date and release notes.
- Install, update and open apps; new ones go beside Solanum in `/data/homebrew/<title ID>`.
- Updates lists the installed apps with a newer release and their changelogs; Installed shows where each lives.
- An interrupted download goes on where it stopped.
- Updates itself from this repository's releases.

Check the download with `gh attestation verify PPSA76526.zip -R Oliv3rmoon/Solanum`, or against `SHA256SUMS`.
